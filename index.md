# Home Server Backup

Aplicativo de uso pessoal mantido por murilo186 para fazer backup de arquivos de um servidor doméstico no Google Drive usando o rclone.

A integração permite enviar arquivos, consultar os backups e recuperar cópias quando necessário. O acesso é autorizado pelo proprietário da conta Google e limitado aos arquivos e pastas criados pela integração, usando a permissão `drive.file`.

Este site contém apenas informações sobre o aplicativo. Os arquivos de backup e as credenciais não são publicados aqui.
